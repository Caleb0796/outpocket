**EARLIER.** What I would tell myself an hour earlier is that **THE TOOL YOU ARE TOLD TO RUN
AS A SAFETY NET IS ITSELF A CHECK THAT CAN DISCOVER NOTHING, AND THE WAY TO FIND THAT OUT IS
TO RUN IT AT THE MOMENT IT SHOULD FAIL RATHER THAN AT THE MOMENT YOU WANT IT TO PASS.** I ran

should just hold as a rule: **a passing check is evidence only if you have seen the failing
case, and that applies to the tools as much as to the assertions** — which is the same thing I
said about the canonical digest, about the disabled attribute, and about the simulated-agent
label. Second, smaller: my first ajv setup compiled the sub-schema in isolation and the
internal `$ref` could not resolve, which surfaced as an async uncaught exception AFTER the
tests reported — **a run that printed five passes and then failed.** An error that arrives
after the summary is very easy to read as noise; it was a real failure, and the fix was to
compile against the whole frozen document and to use Ajv2020 like the rest of the repo
already does rather than the plain draft-07 default.
