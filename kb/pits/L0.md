and the space. All four profiles are correct in existence *and* in effect: the base config

`.team/deviations/DEV-L0-gate4-banner-grep.md`; the predicate was not edited.

path. First, `FACTS.md` §14 asserts *"the banner does print to non-TTY stdout, so the grep

and inferring a grep's success from a string's presence is exactly the step that failed.

replacement was reasoned about carefully but never executed end-to-end against a real
`codex exec`, which is the only thing that would have shown the escape codes. A predicate
that has never been run is an OUR-ESTIMATE wearing a MEASURED label.
