**THE PORT BUG IS THE FIND, AND IT IS THIS SPRINT'S SIGNATURE SHAPE IN A NEW PLACE.**
`Number(process.env.PORT) || 3000` treats **0 as falsy**, so `PORT=0` — the idiom for "give me
an ephemeral port" — silently fell through to 3000. `curl-403.sh` and `toctou.sh` both
believed they were binding ephemeral ports and were **accidentally binding 3000 every time.**
Both scripts passed throughout. The claim "these tests use ephemeral ports" was false for as
long as it had been made, and nothing could have told us: **a test that passes on the wrong
port passes.** The follow-on is sharper still — the boot log printed the REQUESTED port rather
than the BOUND one, so the moment the first fix worked, both scripts' port-scraping would have
broken and the failure would have looked like the fix's fault.
