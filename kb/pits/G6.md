# Pit — G6

Reported by **QA** under D-31, transcribed and committed by L1 from QA's own report.

**TRIED.** Wrote `tools/contracts-check.mjs` to the accept sentence rather than to a mental model
of what a conformance runner "should" do: ajv-2020-12 every `*.schema.json` in `erp/contracts/`
against its own `$schema`, validate each schema's `examples` against itself, recompute every
published digest in `policy-versions.json` with `src/canonical.js` and compare byte-exactly
including `canonical_bytes`, resolve every tool name in `tool-surface.contract.md` to a
definition, and run CHECK 3b.

**HAPPENED.** All green — 16/16 tool names resolve, both `policy-versions.json` digests and
their `canonical_bytes` match, and CHECK 3b agrees in `blocking`, in `warning` and in the
identifying-quadruple set. Two things went wrong on the way and neither was in the node:

- **I invented a requirement the accept does not state.** I had the runner fail a schema with no
  `examples`, on the inference that every schema needs them because most of them have some. One
  schema deliberately carries an elided example to avoid a one-state excerpt that would fail
  check 1. Fixed the script to treat zero examples as a **no-op, not a failure**.
- **My commit was blocked by a lint failure that predates my node entirely.**
  `node tools/lint-layer0.mjs` was failing on `.team/contracts/G4.txt`, and I confirmed against a
  **clean HEAD** that it had nothing to do with my change. I recommended that G4's exclusion list
  needs `.team/contracts/**`, or an equivalent carve-out for dispatch text that quotes banned
  strings in order to describe them.

**CHANGED.** Nothing about the node's logic changed after that catch — the only edit was
**removing my own invented over-strict requirement**. Nothing in `erp/graph.json`.

**EARLIER.** Two. Do not infer "every schema needs examples" from the fact that most of them
have some — **read the accept sentence's actual verb.** And: **run the lint hook on a clean HEAD
before writing anything**, the same way `--run-clean` isolates environment contamination. It
would have shown the blocker before I had built confidence that the commit path was clear.

**GRADE.** MEASURED. G6 itself is fully green and evidenced; `evidence/G6-contracts.txt` carries
the run. The commit was blocked by an already-merged file and by a hook, not by anything in the
node.

is broken", against a clean HEAD, before touching its own work — is the correct method and it is
the one that stopped it from editing a working node to chase someone else's failure.
