**The authoring rule this pit now follows, and why it exists.** `kb/pits/**` was briefly excluded
from G4's repo-wide sweep on a principle I wrote, which covered two classes in one sentence:
generated files that are verbatim extracts of an already-excluded file, and prose whose subject
is the ban. The first class is sound. The second is not, and the peer session `mcp-6d` proved it
by planting an ASSERTED retracted claim inside a pit on an isolated tree and watching the sweep
exit 0 with zero hits. A pit is AUTHORED, not generated; it can carry a claim that exists nowhere
else; and nothing else in this project reads pits. Excluding them bought a false-positive class
at the price of the only instrument that would ever check them. **A pit NAMES the ruling and
states the correct claim; it does not quote the retracted string verbatim.** That costs nothing —
naming R-20 and giving the computed count is strictly more informative than quoting the sentence
R-20 killed. If a pit ever genuinely needs the literal, that is a deviation ticket, not a silent
exclusion.
