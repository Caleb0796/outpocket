## Iron rules you must not violate

Registration is **top-level document only** — nothing in an iframe is ever
discovered. Sole entry point `document.modelContext.registerTool(def, {signal})`;
de-registration only via `AbortController`; no `outputSchema`; annotations are
`readOnlyHint` and `untrustedContentHint` only **in page JS — the CDP
`toolsAdded` event spells the same two fields `readOnly` and `untrustedContent`,
so pick a channel deliberately** (MEASURED 2026-08-29). Revocation does **not**
cancel an in-flight `execute`, and neither does `WebMCP.cancelInvocation`:
MEASURED 2026-08-29 on **152**, `execute`'s `opts` has zero own keys — there is
no signal to receive — so the page runs to completion and its result is
discarded. Your rig must not assert that anything interrupts a running call.
Also measured on both channels: a revoked tool and a never-registered tool are
**indistinguishable** — `invokeTool` answers `-32602 "Tool not found"` for both,
so never assert the browser tells them apart. Secure
context: `localhost`/`127.0.0.1` work, `192.168.x.x` and `.local` yield a silent
`undefined`. `Origin-Agent-Cluster: ?0` silently kills WebMCP — and **only `?0`**;
`?1` is the opposite setting and is harmless, so never write a check that fails on
the header's mere presence. Measured: `registerTool` ≈37 µs/tool amortised; abort
≈1.1 µs/tool; 13 tools p50 0.5 ms. **CDP screenshot latency ≈50 ms is frame
quantisation, not CPU — never add it to or divide it by main-thread time.** All
existing WebMCP measurements were taken with **no agent connected**, so
`registerTool` returned **a `Promise` that resolves to `undefined`** and what was
measured is renderer bookkeeping only. Say this whenever you quote those numbers.
*(Corrected 2026-08-29: "returned `undefined` synchronously" was graded MEASURED
and is wrong on the installed binary. The conclusion survives — no tool handle
comes back, `AbortController` is still the only revocation path — but a timing
loop that does not `await` is timing promise creation, so do not re-measure the
µs figures without awaiting, and do not present them as yours.)*

## Output format

Per node, and the V verdicts are **JSON evidence files**, not prose:

```
NODE:     V3
FILES:    evidence/V3.json
VERDICT:  same-session | no-cookie | different-session   (the schema's own enum)
GRADE:    MEASURED | UNVERIFIED
HOW:      <exact command or click path>
SAW:      <raw output, trimmed but not paraphrased>
MEANS:    <one sentence: which kernel or node this decides>
PIT:      kb/pits/V3.md
```

`UNVERIFIED` is a legal verdict and V6 accepts it — provided the row names an
existing node id as its fallback. A hedge is not a verdict.
