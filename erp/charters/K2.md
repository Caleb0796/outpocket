## Why you exist, stated as a mechanism

**Failed reasoning is unrecoverable from finished documents.** A published claim
carries no trace of the four hostile review rounds that shrank it, or of the
three separate occasions on which a keyword-derived "empty cell" turned out to be
a vocabulary artefact. The finished artefact is exactly the thing that has been
scrubbed of its own history. So you write during, not after.

## Day-0 seed — write this before anything else happens

- **The meta-lesson, first line of the file.** *A keyword-count-derived "empty
  cell" is a vocabulary artefact until it has been re-tested at the concept
  level.* Every strict regex that returned 0 out of 623 was found to have
  occupants when re-tested conceptually. **This same error has now recurred
  three times.** Any future whitespace claim requires a concept-level re-test
  before it may be written.
- **Uncitable sources and why.** **WindTunnel** — its WebMCP arm injects a
  self-built bridge via Playwright and never goes through Chrome's WebMCP at
  all; its publisher sells a WebMCP integration plugin. **arXiv 2508.09171** —
  same name, different object (an independent client-side scheme); citing it is
  an immediate puncture. **TDS "Prompt Engineering Fails Quietly"** — a
  deterministic mock simulator in which zero model calls occurred. Record these
  as **banned citations with reasons**, so the ban survives the reason being
  forgotten.
- **Effect-size discipline.** Pre-registered effects run **2–4×**, not 20×.
  Wilcoxon needs n≥6. The unit of analysis is the **task variant**, not the run.
  The "adding semantically similar tools costs 8–19%" figure was read from the
  wrong column; the real range is 1–8%, median ~3%, and the paper itself judged
  that column an evaluation artefact.
- **Measurement traps already paid for.** CDP screenshot latency ≈50 ms is
  **frame quantisation, not CPU** (40 samples, 39 landing within 3 frames ±1 ms)
  and must never be added to or divided by main-thread time. All WebMCP
  performance numbers on record were taken **with no agent connected**, so only
  renderer bookkeeping was measured — quote them with that caveat attached or not
  at all.

  > **The caveat's CONCLUSION stands; its PREMISE was wrong, and the correction is
  > itself a method lesson worth filing.** This bullet used to justify itself with
  > *"`registerTool` returned `undefined` synchronously"*. **MEASURED on Chrome
  > 152.0.7977.64: `registerTool` returns a `Promise`** (`[object Promise]`,
  > `isPromise=true`) that resolves to `undefined`. So the reason those numbers
  > measure only renderer bookkeeping is *no agent was connected*, which is true
  > and sufficient on its own — not the return type, which was misread. **A timing
  > loop that does not `await` measures promise creation, not registration**, so
  > any figure taken that way is worse than caveated: it is measuring the wrong
  > thing. `FACTS.md` §2 ERR-2 and `EVAL.md` carry the retraction. File this as the
  > pattern — *a correct conclusion propped on a false premise survives review right
  > up until someone checks the premise, and then the whole bullet dies with it.*
- **The self-disclosure rule.** These documents exist for experts to find fault
  with. Volunteering a weakness scores better than having it found. Record which
  self-disclosures actually paid off this sprint.

## Your acceptance bar

- Every entry carries a grade — `MEASURED` / `PUBLISHED` / `VENDOR-CLAIMED` /
  `OUR-ESTIMATE` / `UNVERIFIED` — and a date.
- Every `adopt` ticket and every `NOT ENOUGH` ruling produces one entry or an
  explicit "no method lesson" note, same day.
- `kb/method/BANNED-CITATIONS.md` exists (L0 seeds it) and each ban carries its
  reason. A ban without a reason will be reversed by the next person who finds
  the source plausible.
- At the end, **record the sprint's actual adopt / send-back / debt split** and
  mark it `MEASURED`, replacing the `OUR-ESTIMATE` one-third prior in
  `erp/TEAM.md` §6. That number is the single most reusable thing this sprint
  produces about running this crew again.
- **The three-probability incident is a case, not a dataset.** TEAM.md §3 cites a
  self-estimated figure carried forward beside externally-ruled ones. Only the
  7.5% codex review figure is recorded in `HANDOVER.md`; the other two are not
  carried over. Record the incident, grade it OUR-ESTIMATE, and do not let the
  numbers themselves be quoted as measurements — that is the same error the
  incident is about.
