Your launch command carries a flag that is not optional:

```bash
codex exec -p builder -s workspace-write \
  -c sandbox_workspace_write.network_access=true \
  "$(cat .team/contracts/<node>.txt)" < /dev/null
```

MEASURED: bare `-s workspace-write` renders "Network access is restricted", so
`npm install` fails inside it. And `< /dev/null` is mandatory — with a non-TTY
stdin, `codex exec` prints "Reading additional input from stdin…" and appends
whatever it finds as a `<stdin>` block, silently extending your prompt. Also
MEASURED: `-p <missing-profile>` **exits 0 with no warning** and falls back to the
base config, so if your run banner does not say `reasoning effort: medium`, your
profile did not take and you say so before you build anything.

## API iron rules — authoritative, MEASURED on this machine unless noted

1. Sole entry point: `document.modelContext.registerTool(def, {signal})`.
   `navigator.modelContext` removed in Chromium 150. The installed major is
   **152.0.7977.64** (MEASURED); what the alias does on 152 is node V0.
2. `provideContext` / `unregisterTool` / `clearContext` are gone. De-register
   **only** via `AbortController`.
3. Tool def shape: `{ name, description, inputSchema, annotations, execute(args, opts) }`.
4. **`outputSchema` does not exist.** Annotations are exactly `readOnlyHint` and
   `untrustedContentHint`.
5. Budgets: `description` ≤ 500 chars, output ≤ ~1500 chars. These are
   **PUBLISHED official guidance, not enforcement** — grade them PUBLISHED, never
   MEASURED. Truncate logs.
6. The browser does **not** validate against `inputSchema` — it parses JSON and
   checks for an Object. Chrome's own guidance: validate strictly in code,
   loosely in schema. **Every write tool validates its own arguments.**
7. **Never encode workflow order in a description.** "Call A first" is wrong.
   Registration/de-registration *is* the state machine.
8. **Top-level document only.** Nothing registered inside an iframe is ever
   discovered — same-origin or cross-origin. Any design that registers from a
   receipt preview or signature panel inside an iframe fails silently.
9. Chrome 153+: de-registration does not cancel an in-flight `execute`. Never
   write copy or code that claims revocation stops the call already running.
10. **No binary channel.** Agents cannot deliver images or PDFs. Attachments are
    human-uploaded; an agent may only link an existing id.
11. `Origin-Agent-Cluster: ?0` silently kills WebMCP. If CSP is set, `script-src`
    needs `'wasm-unsafe-eval'` for any WASM.
12. Secure context: `localhost` / `127.0.0.1` work; `192.168.x.x` and `.local`
    silently yield `undefined`.
13. Flags differ by purpose: manual/attended testing
    `--enable-features=WebMCPTesting`; automation/CDP needs
    `--enable-features=WebMCP`. Using the wrong one yields a silently toolless
    page. Note the open gap: the one measurement we have that `getTools()` works
    was taken under `WebMCPTesting`, and node H2's first hour is what confirms it
    under `WebMCP`.
14. ChatGPT built-in browser: GPT-5.6 **Sol or Terra** only (Luna disabled), not
    on Enterprise/Edu, no declarative API.
15. Measured cost: `registerTool` ≈ 37 µs/tool amortised; abort-revocation
    ≈ 1.1 µs/tool. Registration is cheap; do not micro-optimise it.
16. A dynamic surface costs ≈1.25× prompt-cache write per flip. **Never claim it
    saves tokens.**
