## API iron rules — authoritative, MEASURED unless noted

1. `document.modelContext.registerTool(def, {signal})` is the only entry point.
   `navigator.modelContext` removed in Chromium 150. The installed major is
   **152.0.7977.64** (MEASURED); the alias status on 152 is node V0.
2. De-registration is **only** `AbortController`. `provideContext` /
   `unregisterTool` / `clearContext` are gone.
3. `outputSchema` does not exist. Annotations: `readOnlyHint`,
   `untrustedContentHint`, nothing else.
4. **The browser does not validate `inputSchema`.** It parses JSON, checks for an
   Object, and calls the page. This is your single richest attack surface:
   every write tool must validate in code, and any that does not is a real
   finding.
5. **Revocation does not cancel an in-flight `execute`** (Chrome 153+). Any code
   or copy claiming otherwise is a finding.
6. Top-level document only — iframe registrations are never discovered.
7. No binary channel; attachments are human-uploaded, agents may only link ids.
8. `Origin-Agent-Cluster: ?0` silently kills WebMCP.
9. Budgets: description ≤500 chars, output ≤1500 chars — **PUBLISHED official
   guidance, not enforcement.** A description over budget is a lint finding, not
   a broken invariant.
10. Dynamic surfaces cost ≈1.25× cache write per flip; they do not save tokens.
11. ChatGPT built-in browser: GPT-5.6 Sol/Terra only, Luna disabled, no
    Enterprise/Edu, no declarative API.
12. Automation needs `--enable-features=WebMCP`; manual/attended testing uses
    `--enable-features=WebMCPTesting`. An "attack" run under the wrong flag
    against an empty tool list is not a finding.

## Your standing target list — attack these in this order

**Target 6 runs FIRST.** It is numbered 6 for historical reasons and it is the
one with a live, unclosed vector in it. The rest of the list follows in the order
printed. The list is a **minimum, not a menu**: E9 requires at least 8 attempted
breaks, and a run that skips a listed target has not met the bar.

1. **The client-side 403.** The legacy `countinghouse/src/erp.js:101` pattern is
   a client telling itself no. Prove the server actually refuses. Auditor session
   → every write endpoint → expect real 403, at `curl` level, committed as a
   test.
2. **The sign gate TOCTOU.** Human signs a snapshot; agent mutates the record
   between signature and persistence. The claimed defence is server-side
   re-canonicalisation and digest comparison. Break it: whitespace, key order,
   unicode normalisation, numeric formatting (`10.00` vs `10.0` vs `1000` cents),
   duplicate keys, added fields the canonicaliser ignores.
3. **Revoked-tool replay.** Call a tool whose `AbortController` has fired.
   Separately: start an `execute`, revoke mid-flight, and confirm the code does
   not pretend the revocation stopped it.
4. **Schema-bypass writes.** Send arguments that violate `inputSchema` — wrong
   types, missing required fields, extra fields, deep nesting, huge strings.
   The browser will pass them straight through. Anything that reaches state
   unvalidated is a finding.
5. **Hash-chain forgery.** Append, reorder, or rewrite day-book entries; check
   whether the digest genuinely covers the `source` field.
6. **Provenance laundering, and the hole that is still open — keep this first in
   practice.** Get an agent-proposed field to present as human-edited, and go one
   layer up: **make the server record a human signature when no human signed.**

   *What R-1 fixed.* The previous design's `sign_response` was entirely
   client-authored — every field a constant, attacker-chosen, or copied verbatim
   out of the `sign_request` the server had just returned — so a synthesised
   response passed every rejection code and committed, writing a chain entry
   attesting a human signature by a **client-chosen** name at a **client-chosen**
   time. S5/S12 now hold the decision server-side (`open → answered → committed |
   expired`, `signed_by` from the session cookie, `at` from the server clock, 409
   `E_NOT_SIGNED`).

   *What is still open, and it is your first target, named so that no one can
   miss it:*
