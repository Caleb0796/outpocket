# Stall register

One row per seat that has gone quiet. **W** gathers the evidence, **L1** records the row,
**PM** rules. Nobody here can restart a dead resident session — `erp/FACTS.md` §14: an agent
cannot open a new terminal window, and a genuinely dead resident session needs a human.

The escalation is fixed: quiet seat → **W** for evidence → **PM**. Do not re-dispatch a node
to a second seat before PM has ruled; two seats on one branch is the ownership collision this
register exists to prevent.
